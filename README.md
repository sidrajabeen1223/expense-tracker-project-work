# Student Expense Tracker

A beginner-friendly expense tracker built with HTML, CSS, and vanilla JavaScript.

## Features
- Add expenses with a description, amount, category, and date
- View total expenses, current-month expenses, and transaction count
- Filter expenses by category
- Delete one expense or clear all expenses
- Save data in the browser with `localStorage`
- Responsive layout for desktop and mobile screens

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add your expenses.

No installation or server is required.

## Files
- `index.html` — page structure and form
- `style.css` — responsive styling
- `script.js` — expense handling, totals, filtering, and browser storage

## Note
Expenses are stored only in the current browser on your device. Clearing browser site data may remove them. This is a learning project, not a bank-connected financial application.
